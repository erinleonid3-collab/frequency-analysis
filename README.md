# Frequency Counter (Подсчет частоты элементов)

## Описание задачи
Метод получает на вход массив элементов и возвращает `Map`, где:
* **Ключ** — уникальный элемент из массива.
* **Значение** — количество раз, которое этот элемент встретился в массиве.

Метод использует **параметризацию (Generics)**
